# 서사 분석과 이어쓰기의 연구 근거

이 문서는 중단된 소설의 기존 내용을 분석하고 이어 쓸 제품의 **분석 항목과 작업 흐름을 설계하기 위한 참고**다. 아래 논문의 개념에서 착안했지만, 해당 논문에 나온 알고리즘을 그대로 구현하거나 재현했다고 주장하지 않는다. 문헌별 짧은 적용 메모는 [`config/research.json`](../config/research.json)에 있다.

## 분석 차원

| 차원 | 설계에 반영할 개념 | 범위와 주의점 |
|---|---|---|
| 인물 | 인물의 행동·피동·속성 묘사를 작가 문체 효과와 함께 살펴보는 관점 ([Bamman et al., 2014](https://aclanthology.org/P14-1035/)) | 이 논문은 영어 역사소설의 잠재 인물 유형을 연구했다. 작품의 정체성이나 동기를 자동 판정하는 근거는 아니다. |
| 사건·시간 | 공통 인물에 연결된 사건 묶음과 부분적 시간 순서 ([Chambers & Jurafsky, 2008](https://aclanthology.org/P08-1090/)) | 사건의 연관성·선후 관계를 인과관계로 단정하지 않는다. 장편 이어쓰기 흐름은 [Re3](https://aclanthology.org/2022.emnlp-main.296/)와 [DOC](https://aclanthology.org/2023.acl-long.190/)의 계획·상태 갱신 아이디어를 개념적으로 참고한다. |
| 세계관 | 장소, 규칙, 역사, 관계에 대한 명시적 사실 목록과 모순 점검 | **엔지니어링 추가 항목**이다. 참고 문헌은 이 전체 세계 상태 모델을 검증하지 않았다. 사건 사슬 연구도 세계 규칙 추적 알고리즘을 제공하지 않는다. |
| 서술 | 구술 개인경험담의 orientation, 사건 전개, evaluation, resolution, coda를 선택형 질문으로 활용 ([Labov & Waletzky, 1967; 1997 reprint](https://doi.org/10.1075/jnlh.7.02nar)) | 구술 서사 분석 관점으로만 참고한다. 소설의 장·시점·순서를 규정하는 틀로 쓰지 않는다. |
| 문체 | 어휘·문장 특징을 기록하고 인물 표현과 작가 문체가 섞일 수 있음을 고려 ([Bamman et al., 2014](https://aclanthology.org/P14-1035/)) | **엔지니어링 추가 항목**이다. 논문은 문체 모방이나 작가 스타일 복제 알고리즘을 검증하지 않았다. |
| 주제 | 작품에서 반복되는 주제 후보를 근거 문장과 함께 기록하고 사람이 검토 | **엔지니어링 추가 항목**이다. 여기 참고한 문헌에서 검증된 주제 추출 알고리즘은 없다. |
| 서사선 | 진행 중인 인물·목표·미해결 갈등·마지막 확인 위치를 별도 상태로 보관. 개요와 현재 이야기 상태를 이용한 생성은 [Re3](https://aclanthology.org/2022.emnlp-main.296/)·[DOC](https://aclanthology.org/2023.acl-long.190/)에서 개념적으로 참고 | **엔지니어링 추가 항목**이다. 복수 서사선 추적, 원작의 상태 보존, 미완결 웹소설 이어쓰기는 이 논문들의 입증 범위가 아니다. |
| 감정 흐름 | 장·구간별 감정 신호를 시각화해 흐름을 살펴봄 ([Reagan et al., 2016](https://doi.org/10.1140/epjds/s13688-016-0093-1)) | 분석 대상은 Project Gutenberg의 선별된 영어 소설 1,327편이다. 제시된 여섯 곡선 유형을 보편 법칙이나 품질 기준으로 강제하지 않는다. |

## 이어쓰기 흐름에 대한 적용

긴 원문을 한 번에 요약하는 대신, 작품 전체 개요와 인물·사건 상태를 유지하면서 본문 구간 단위로 분석·생성하고 결과를 다시 상태에 반영하는 방식을 고려한다. [Re3](https://aclanthology.org/2022.emnlp-main.296/)는 계획과 현재 이야기 상태를 이용해 여러 이어쓰기를 비교하고 사실 일관성을 수정하는 단계가 긴 이야기에서 도움이 될 수 있음을 보였다. [DOC](https://aclanthology.org/2023.acl-long.190/)는 계층형 상세 개요와 본문 구간 생성의 제어를 평가했다. 이 결과는 해당 논문들의 설정에서 나온 것이며, 본 제품의 한국어 소설 분석이나 원작 모사 품질을 보증하지 않는다.
