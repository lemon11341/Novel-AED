# Changelog

## 0.1.1 — 2026-11-07

- When `doctor` or `mcp` finds no verified runtime, the error now shows the requested storage location so setup can be rerun with the same `--home` or `NOVEL_AED_HOME`.
- Windows junction verification tests now support Python 3.11.

## 0.1.0 — 2026-11-07

- Local MCP server with 17 tools, workflow resources, and a matching novel-aed skill.
- Shared CLI/MCP validation and explicit approval history.
- npm launcher with preview, setup, backup-based connection updates, and diagnostics.
- Persistent versioned Python runtime and separate manuscript storage.
- Release allowlist, packed-distribution installation tests, and opt-in npm publishing workflow.
